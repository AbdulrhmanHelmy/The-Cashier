## Final closure verification

- **P6-02 remains an existing contract limitation.** The catalog detail response provides prices and units. Only purchase create/update and saved-invoice reads return the authoritative invoice-line amount, after the server applies its quantity/price policy. The dash on an unsaved or financially edited line accurately signals that there is no current saved value. The aggregate preview remains available. An authoritative pre-save line amount requires separate business/API authorization.
- **P6-15 and P6-18 were rechecked.** Edge against disposable SQLite opened the actual saved invoice preview, matched its reference and supplier, displayed the separated fields, and closed with Escape. Physical printing was reported by the owner from prior testing. Native printer qualification and native Purchasing interaction were untested in this closure.
- No new Purchasing UI defect was verified. Native startup passed and the authenticated native workflow remains open. See [final closure QA](purchases-stage6-qa.md#final-closure-pass).
