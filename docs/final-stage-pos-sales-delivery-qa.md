## Reproduction commands

- Run `node frontend/tests/final-sales-browser.cjs` for focused Edge evidence and add `--matrix` for route smoke. Set `THECASHIER_QA_PLAYWRIGHT` if Playwright Core is installed outside normal Node resolution.
- Run `node frontend/tests/run-tests.js` for frontend regressions. Run `dotnet test tests/AlKhayal.IntegrationTests/AlKhayal.IntegrationTests.csproj -c Release --no-restore -m:1 --filter FullyQualifiedName~Delivery_` for delivery integration.
- The 20-trial case asserted the original and revised IDs, revised address, assigned or unassigned driver, unchanged confirmed total, filtered current ID, and persistence after a fresh host start for every iteration. Status expectations cycle pending, out for delivery, delivered and failed. The single passing xUnit result required every iteration to complete. [Trial output](../artifacts/final-stage/delivery-20-trials.txt)
- The live Edge runner takes the disposable host directory as its first argument. Its per-trial log records all 20 successes, themes, dimensions, invoice numbers, original and revised IDs, statuses, and assignment state. The runner intercepted only automatic printer dispatch and asserted persisted IDs and addresses after reopening. [Live trial log](../artifacts/final-stage/edge-live-delivery.txt) · [Checkout confirmation](../artifacts/final-stage/live-checkout-confirmation.png) · [Correction](../artifacts/final-stage/live-confirmed-correction.png)
- Add `--sales` against the same running disposable host after the 20-trial run for report linkage, sales lookup, PDF, receipt preview and cancellation. Cash reversal is unavailable under the current backend policy. A subsequent GET confirmed cancellation of the unpaid credit invoice.
