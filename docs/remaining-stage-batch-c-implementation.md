# Batch C implementation

Backup settings name the configured folder above its history. Manual backup confirmation continues to show the API-returned file path and size. When a successful history refresh omits the file, the confirmation directs the operator to its returned server path. The existing download affordance remains tied to inclusion in the returned history. A failed refresh continues to report its error. See the [defect register](remaining-stage-batch-c-defect-register.md).

The Users view keeps permission dialogs associated with the most recent request. An older response cannot replace the more recent cashier dialog. Opening another user action or reloading the directory supersedes pending permission-dialog results.

Company profile and general settings keep the form read-only during the existing save, including its local Cancel button. When the request settles, controls enabled before submission are restored and the existing success or error feedback applies.
