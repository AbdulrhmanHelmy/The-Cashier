# AlKhayal POS direct full setup 1.0.12

`scripts/AlKhayal-Production-1.0.12.iss` builds a single installer from the current Release UI output and frontend. It does not execute the 1.0.9 setup or a second update setup. No database, activation file, License Manager, private key or issuer is packaged.

The actual 1.0.9 installer was inspected with innounp 2.71.3. Its Inno AppId is `{C6042F26-9F4C-42D4-B1BE-377779271777}`, its application directory is `{autopf32}\AlKhayal POS`, it allows Windows 7 SP1 and x86/x64-compatible systems, and it installs a loopback URL ACL for port 5137. These values are preserved. The 1.0.9 package contained .NET Framework 4.8 offline, WebView2 Evergreen x86 offline and Microsoft Edge x86 109.0.1518.140. The new package carries those exact three Microsoft-signed prerequisites. It additionally carries the Microsoft Update Catalog's signed WebView2 Runtime x86 109.0.1518.140 package for Windows 7, because Edge 109 by itself does not prove a WebView2 Runtime is installed. Existing runtime installations are detected and left alone; missing prerequisites are installed before current application files are copied. Any failed prerequisite stops setup.

On Windows 10/11, the bundled x86 Evergreen installer is used if WebView2 is missing. On Windows 7, the bundled Edge 109 and WebView2 109 installers are used if WebView2 is missing. Windows 7 SP1 and its servicing prerequisites remain requirements. The exact Windows 7 flow and a 1.0.9-to-1.0.12 upgrade have **not** been executed in an isolated VM; the archive inspection and package compilation do not establish that runtime compatibility. Customer deployment must wait for that acceptance test. The previously generated 1.0.10 wrapper and 1.0.11 modern-only setup are obsolete for this release.

Sources: [Microsoft WebView2 distribution](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution), [Microsoft Update Catalog WebView2 109 x86](https://www.catalog.update.microsoft.com/Search.aspx?q=109.0.1518.140), [.NET Framework 4.8 offline runtime](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48).
