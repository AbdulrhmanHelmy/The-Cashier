# Batch A implementation

Return picker dismissal now resolves to the prior selection and restores keyboard focus. Payment directories and instrument histories paginate independently. Synthetic requests reproduce both behaviors in `frontend/tests/remaining-browser.cjs`. The same Returns UI and existing API serve sales and purchase returns. The registry aliases both entry points to the unified overview and the picker provides separate types and API-backed eligibility. See the [defect register](remaining-stage-batch-a-defect-register.md).
