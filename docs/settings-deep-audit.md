## Evidence boundaries

The Edge matrix uses current files and isolated API fixtures at 1024×768, 1366×768 and 1600×1000 in both themes. These are real screenshots of current browser rendering. Fixture values, response failures and delays are named as such. The primary matrix used shallow stub responses outside the print/general/company paths, so initial log, label, backup and attendance images do not establish populated behavior. A synthetic shell shift indicator in the primary fixture is not a product finding. Static source review covered save/validation and access boundaries. Existing Stage C evidence supplements the fixture review. Native WebView2, exhaustive input and keyboard permutations, real saved document previews, physical printing and restore were NOT TESTED. The pre-existing working-tree changes were treated as the current baseline.

The frontend regression command `node frontend/tests/run-tests.js` passed, including registry validation for 132 screens, printer and barcode suites, backup, operation log and permission lifecycle. No fresh Release build or full integration suite was run for this diagnosis. See the [screenshot index](settings-audit-screenshot-index.md) and [approval plan](settings-improvement-plan.md).
